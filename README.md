# 锅盖雪人 · 云上城

**直接双击 `锅盖雪人.html`，用电脑浏览器打开即可游玩。** 无需安装、服务器、账号或网络。浏览器若只显示源代码，请用“打开方式 → Chrome / Edge”。

四个连续房间：龙卫门廊 → 悬空回廊 → 石像工坊 → 城主大厅。普通、冒险、王者三档。清场开启右侧光门，走进去换房；最后清场获胜，HP 归零失败。每房过门恢复 18 HP。

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 横向及纵深移动 |
| J（可按住） | 三段剑击 |
| K | 跳跃，离地时躲地面攻击 |
| L | 直线穿透飞锅，3 秒冷却 |
| U | 冰环范围伤害与冻结，7 秒冷却 |
| 空格 | 移动方向冲刺，短暂无敌，1.2 秒冷却 |
| H | 使用药水 +45 HP，每局 2 瓶 |
| Esc / P | 暂停/继续 |
| R | 胜利或失败后同难度重开 |

打法：和敌人对齐纵深，面向敌人按 J；先用冰环冻住一群再连击，用飞锅打远处法师。红色圆圈是伤害预警，走开、跳跃或冲刺躲避。领主半血后攻击加速。

## 源码与重建
- `index.html` / `style.css` / `game.js`：页面、样式、规则和像素角色。
- `assets/sky-castle.png`：原创 AI 生成背景；已嵌入离线 HTML。
- `build.mjs`：Node.js 构建脚本。在本目录执行 `node build.mjs` 更新单文件 HTML，无 npm 依赖。
- `DESIGN.md`：调研来源、规则、美术与简化范围。
- `TESTING.md`：实际验证与已知限制。

当前是 DNF 风格的简化单机副本，不是原版完整复刻。角色是原创锅盖雪人像素图形；没有原版贴图、音乐、职业、养成、掉装或多人联网。四房共用一套城堡美术，使用镜像与房间陈设区分。技能与数值为原创改编。

桌面键鼠使用；未提供移动端触屏控制。失焦自动暂停。场景加载失败时有程序绘制的城堡回退画面。音效由 Web Audio 合成，右上角可关闭。

开发者复跑浏览器规则验证：`npm install`，`npx playwright install chromium`，`npm test`。测试结果写到 `test-results/`，不会修改游戏规则。正常游玩无需这些步骤。

## 持续维护

代码仓库：https://github.com/Transcendo/dnf-astra 。Multica 项目：`dnf-astra`，首期任务 `KARL-10`～`KARL-13`。

克隆后执行 `npm ci` 安装开发依赖，`npm run build` 更新离线 HTML。后续功能通过分支与 PR 维护，所有源文件、原创素材和生成的单文件一起纳入版本控制。GitHub Actions 在 main 推送或 PR 时执行构建和 Chromium 测试，并检查离线 HTML 是否与源码一致。
