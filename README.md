# 锅盖雪人 · 云上城

**直接双击 `index.html`，用电脑浏览器打开即可游玩。** 无需安装、服务器、账号或网络。浏览器若只显示源代码，请用“打开方式 → Chrome / Edge”。

四个连续房间：龙卫门廊 → 悬空回廊 → 石像工坊 → 城主大厅。普通、冒险、王者三档。清场开启右侧光门，走进去换房；最后清场获胜，HP 归零失败。每房过门恢复 18 HP。

| 按键 | 操作 |
| --- | --- |
| WASD / 方向键 | 横向及纵深移动 |
| J（可按住） | 随武器变化的三段魔法连击 |
| K | 跳跃，离地时躲地面攻击 |
| 1 / 2 / 3 | 法杖 / 魔杖 / 扫把；切换不刷新冷却 |
| L | 当前武器专属技能，冷却见下表 |
| U | 冰环范围伤害与冻结，基础 7 秒冷却 |
| 空格 | 移动方向冲刺，短暂无敌，1.2 秒冷却 |
| H | 使用药水 +45 HP，每局 2 瓶 |
| Esc / P | 暂停/继续 |
| R | 胜利或失败后同难度重开 |

打法：和敌人对齐纵深，面向敌人按 J；先用冰环冻住一群再连击，用魔杖飞弹打远处法师。红色圆圈是伤害预警，走开、跳跃或冲刺躲避。紫圈雷击可对空，须走出范围或冲刺。领主半血后攻击加速，并有 1.1 秒转换提示。

## 部署与入口

唯一发布入口是根目录 `index.html`，其中已内嵌脚本、样式和图片。静态托管以仓库根目录为发布目录，构建命令为 `npm run build`；也可以只发布构建后的 `index.html`。本地直接用浏览器打开同一文件即可。

`index.html.in` 仅为构建模板，不是游玩入口。修改模板、脚本或素材后重新构建，不直接编辑生成的 `index.html`。旧的 `锅盖雪人.html` 已移除；更新已有部署时请清理旧发布文件，并将旧链接改为 `/` 或 `/index.html`。

## 源码与重建
- `index.html.in` / `style.css` / `game.js` / `combat.js`：页面、样式、规则和角色渲染。
- `assets/sky-castle.png` / `assets/mage-snowman.png`：原创生成背景与 24 帧透明魔法师雪人精灵，均已嵌入离线 HTML。
- `sprite-data.js`：帧尺寸、脚底与逐帧武器挂点；`npm run assets:prepare` 从保留的绿底原图可重建精灵。
- `build.mjs`：Node.js 构建脚本。在本目录执行 `node build.mjs` 更新单文件 HTML，无 npm 依赖。
- `DESIGN.md`：调研来源、规则、美术与简化范围。
- `TESTING.md`：实际验证与已知限制。

当前是 DNF 风格的简化单机副本，不是原版完整复刻。默认职业为魔法师；角色已接入紫发、红围巾和银色锅盖的原创雪人魔法师，含待机、移动、施法、跳跃、受击和冲刺贴图；没有原版贴图、音乐、转职树、永久养成或多人联网。四房共享城堡底图，分别加入旗帜门廊、悬浮符文碎石、旋转工坊和领主星环光柱；云层随时间与玩家位置视差移动。技能与数值为原创改编。

桌面键鼠使用；未提供移动端触屏控制。失焦自动暂停。场景或角色图片加载失败时有程序绘制回退画面。音效由 Web Audio 合成，右上角可关闭。

开发者复跑浏览器规则验证：`npm ci`，`npx playwright install chromium`，`npm test`。测试结果写到 `test-results/`，不会修改游戏规则。正常游玩无需这些步骤。

## 三种武器

| 按键 / 武器 | 攻击力 / J 间隔 | 普攻 | L 专属技能 |
| --- | --- | --- | --- |
| 1 法杖 | 30 / 0.48 秒 | 前方宽范围，慢速高伤 | 星落爆破：前方定点椭圆范围，倍率 2.1，冷却 3.8 秒 |
| 2 魔杖 | 13 / 0.17 秒 | 快速直线飞弹，击中首个敌人消失 | 穿星飞弹：直线穿透，每敌一次，倍率 2.6，冷却 2.6 秒 |
| 3 扫把 | 22 / 0.32 秒 | 近身前方宽纵深横扫，移动速度 +18% | 旋风扫击：周身椭圆范围，倍率 2，冷却 3.2 秒 |

三连段倍率为 1 / 1.12 / 1.35；U 冰环为当前攻击力 ×2，基础冷却 7 秒。伤害取整。切换保留 HP、房间、连段、普攻与所有技能的剩余冷却；已发射飞弹保留发射时的武器、伤害和方向。HUD 左侧显示当前武器与差异，下方显示技能剩余冷却。


## 局内成长与统计（KARL-16）

前三房清场后自动拾取星辉，各弹出一次三选一。战斗和计时冻结，鼠标点击或 Tab + Enter 选择后恢复，走入右侧门继续。词条对三武器生效，切换立即更新面板；重开清空全部成长。

| 词条 | 收益 | 代价 |
| --- | --- | --- |
| 重铸 · 强攻 | 攻击倍率 +0.25 | 技能冷却倍率 +0.08 |
| 星晶 · 会心 | 暴击率 +15 个百分点、暴伤 +0.2 倍 | 攻击倍率 −0.05 |
| 轻羽 · 速咏 | 技能冷却倍率 −0.20 | 攻击倍率 −0.05，普攻间隔不变 |

初始暴击率 10%、暴伤 1.5 倍。白色普通伤害、青色“技能”、金色“暴击！”区分反馈。
统一公式：round(武器基础攻击 × 局内攻击倍率 × 连段/技能倍率 × 暴击系数 × 100/(100+防御))。
防御 = 难度防御（普通 0 / 冒险 8 / 王者 16）+ 怪物防御（石像 15 / 领主 10 / 其他 0）。
面板攻击保留一位小数，伤害在完整公式末尾取整。

连击评价 D → C（3）→ B（8）→ A（15）→ S（30）。两秒未命中或受伤断连，显示原因与断连数。
结算显示总伤害、有效战斗秒伤、最高连击、击杀与取得词条。总伤害只累计实际扣血，击杀溢出不计；有效战斗时间仅统计有存活敌人的游玩帧，包括接敌走位，排除暂停、成长选择、清房走门和结算。

三难度分别使用血量 ×1/1.2/1.4、伤害 ×0.85/1.25/1.7、移动与攻击频率 ×0.9/1.12/1.4、预警时间 ×1.15/0.9/0.7。王者主要增加操作压力，仍可通过跳跃、冲刺与走位规避。

## 雪人魔法师动作（KARL-17）

J 有约 73 毫秒蓄势，L / U 有 100 毫秒蓄势，之后释放并收势；按键与冷却不变。武器、方向、攻击力和暴击在按键时快照，切武器不会改写正在蓄势的攻击。三武器分别使用紫晶长法杖、冰青星形短魔杖和金色刷毛扫把；左右面向连同握持点一起镜像。

## 战斗手感（KARL-18）

J 三段倍率为 1 / 1.12 / 1.35，第三段浮空；扫把 L 聚怪并浮空，随后普攻或飞弹可空中追击。普通敌人每轮控制最多 2 秒，随后 1.4 秒脱控（仍可受伤）；冰冻不能突破窗口，领主全程霸体，不可浮空或冰控。已经出现的地面预警不会因冻结施法者而取消。浮空高度受重力影响，追击不刷新高度。

红色地震可跳；紫色雷击可对空且锁定施放时的位置，走位或冲刺可躲。领主每次起手后留 0.65 秒恢复窗口，半血转换留 1.1 秒。切换武器不清除任何冷却或提供无敌。

右上角「特效」减弱粒子、亮度并停用震动，「震动」可单独关闭；不改变伤害与预警。命中顿帧 22ms、暴击 45ms，每 180ms 最多触发一次。所有视觉效果共享 180 个上限；暂停冻结攻击、粒子和预警。

性能复跑：`npm run test:performance`，使用真实时钟进行约 180 秒战斗及 29 次重开，生成帧间隔、粒子峰值、监听器和 GC 后堆数据。

## 第二轮整合交付（KARL-19）

离线入口现统一为 `index.html`，可单独复制到其他目录双击打开。完整版本含三武器、三次局内成长、24 帧雪人魔法师、四房动态场景与领主半血转换；不需要下载额外素材。回复飘字按本次实际回血显示（最多一位小数），满血不消耗药水；掉落满血时不再显示虚假的 +12。

本阶段增加 `tests/integration.cjs`（已纳入 `npm test`）：隔离目录断网启动、双图故障回退、松键与冲刺冷却、暂停清键、音效/特效开关、实际回血与三种桌面尺寸。详细通关和平衡观察、性能数据及未验证范围见 `TESTING.md`。
